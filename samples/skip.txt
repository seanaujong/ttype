This is the third chunk. The "skip chunk" hint only shows before you start
typing, since a skip always resets the run. Once you press a key it steps

The fourth chunk is here to give Tab somewhere to land. Each blank line
between paragraphs is a chunk boundary, so the default chunker turns this
plain-text file into one chunk per paragraph — six in all.

Fifth chunk. Try skipping straight to the last chunk and typing only that —

Last chunk, the sixth. Tab here does nothing: the start clamps to the final
