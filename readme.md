# ttype

ttype is a type racer in your terminal.

## Made with Ink

> This readme is automatically generated by [create-ink-app](https://github.com/vadimdemedes/create-ink-app)

## Install

```bash
$ npm install --global ttype
```

## CLI

```
$ ttype --help

  Usage
    $ ttype

  Options
    --name  Your name

  Examples
    $ ttype --name=Jane
    Hello, Jane
```
